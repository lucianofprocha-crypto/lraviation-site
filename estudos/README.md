# Study Guide — G550 (PWA)

App de estudo G550 para iPad, offline: programa de recorrência (5 semanas, 27 sessões),
21 study guides, 401 flash cards e questionários por capítulo.

## Dois pacotes
1. **Pasta `estudos/`** (este app) — pode ir para o site (GitHub Pages).
2. **`quiz-pack.json`** — questionários CAE (Self Check: 197 questões de múltipla escolha com gabarito;
   Systems Review: 497 perguntas abertas). Material CAE de licença pessoal:
   **NÃO publicar no site nem no GitHub.**

## Instalar os questionários no iPad
Coloque `quiz-pack.json` no iCloud Drive (ou AirDrop) → no app, Biblioteca → Questionários →
"Importar quiz-pack.json". Fica salvo no app e funciona offline. Só precisa importar de novo se
remover o app ou se eu gerar um pacote atualizado.

## Publicar / atualizar o app
Envie a pasta para o repositório (ex.: lraviation.com.br/estudos/). Safari → Compartilhar →
Adicionar à Tela de Início → abrir pelo ícone uma vez com internet.
Ao atualizar, suba a versão no sw.js (study-guide-v4 → v5).
